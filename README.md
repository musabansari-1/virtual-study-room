# Virtual Study Rooms
A collaborative platform for remote study sessions.


## Repositories

- [Frontend Repository](https://github.com/musabansari-1/Virtual-study-room-frontend)) — React, Tailwind CSS
- [Backend Repository](https://github.com/musabansari-1/virtual-study-room-backend)) — Python, Fast API

## Tech Stack

- **Frontend**: React JS
- **Backend**:  Fast API
- **Database**: SQLite

## Getting Started

To run the complete project locally:

1. Clone the frontend and backend repositories.
2. Follow the setup instructions provided in each repo.
